# Vue 3 + TypeScript + Vite

这是一个帮助你在 Vite 中开始使用 Vue 3 和 TypeScript 开发的项目模板。该模板使用 Vue 3 `<script setup>` 单文件组件，查看 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) 了解更多。

了解更多关于推荐的项目设置和 IDE 支持，请参阅 [Vue Docs TypeScript Guide](https://vuejs.org/guide/typescript/overview.html#project-setup)。
